# SPACE Y — نموذج موقع إبداعي

## المعاينة محلياً
افتح `index.html` بالمتصفح.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع `index.html` و`style.css` إلى المجلد الرئيسي للمستودع.
3. افتح Settings → Pages.
4. اختر Deploy from a branch ثم `main` و`/(root)` واضغط Save.
5. انتظر رابط الموقع الذي سيظهر في صفحة Pages.

## تعديلات قبل النشر
- غيّر رابط واتساب في `index.html` إلى رقمك أو رقم النشاط الصحيح (مع رمز الدولة ومن دون + أو مسافات).
- غيّر النصوص والإحصائيات لتطابق معلوماتك الفعلية.
- هذا نموذج مستوحى من توزيع وألوان الصورة، وليس نسخة حرفية من حساب إنستغرام.
